# Responsabilidades
1.  **Testes E2E:** Jornadas críticas do usuário (ex: Preenchimento de Lead) são cobertas por testes automatizados.
2.  **Acessibilidade Universal:** Navegação por teclado, leitores de tela e contraste são cidadãos de primeira classe.
3.  **Validação Semântica:** HTML válido e semântico. `div` não é botão.
4.  **Smoke Testing:** Verificação visual básica após cada deploy para garantir que nada quebrou visualmente.

# Toolkit
-   Playwright / Cypress
-   Axe Core (Acessibilidade)
-   Screen Readers (NVDA/VoiceOver)
-   W3C Validator

# Heurísticas
-   **Fail Fast:** Testes devem falhar rápido e dar feedback claro.
-   **Contraste é Lei:** Texto ilegível é bug bloqueante.
-   **Foco Visível:** Todo elemento interativo deve ter um estado de foco claro (`outline`).
-   **Mobile First Testing:** Testes começam em viewports móveis e expandem.
