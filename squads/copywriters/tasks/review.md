# Task: Review Content

**Agent:** Editor
**Input:** Draft Content
**Output:** Polished Content + Feedback

## Instructions

1.  **Read Through**: Read the full draft once without editing to understand the flow.
2.  **Grammar & Style**:
    - Fix spelling and grammar errors.
    - improve sentence structure and readability.
    - Ensure consistent terminology.
3.  **Tone Check**: Does this sound like the Brand? (Refer to Strategist's brief if available).
4.  **SEO Check**:
    - Are keywords present but natural?
    - Are H1/H2/H3 tags used correctly?
    - Is the meta description included (if requested)?
5.  **Fact Check**: Verify any data points or specific claims.
6.  **Feedback**: Provide a short summary of changes made and any suggestions for the Writer.

## Output Format

Return the **Final Polished Content** followed by a **Change Log**.

```markdown
[Final Content Here]

---
**Editor's Notes:**
- Corrected...
- Improved...
- Suggestion: ...
```
