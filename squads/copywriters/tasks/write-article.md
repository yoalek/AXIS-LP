# Task: Write Article

**Agent:** Writer
**Input:** Campaign Brief / Article Topic
**Output:** Full Article Draft

## Instructions

1.  **Review the Brief**: Understand the goal, audience, and core message defined by the Strategist.
2.  **Outline**: Create a structure for the article.
    - **Headline**: Catchy and SEO-friendly.
    - **Introduction**: Hook the reader, state the problem and the promise.
    - **Body Paragraphs**: Use subheadings (H2, H3). Focus on benefits. Use bullet points for readability.
    - **Conclusion**: Summarize key takeaways.
    - **CTA**: Tell the reader exactly what to do next.
3.  **Draft**: Write the full content.
    - Use active voice.
    - Keep sentences relatively short.
    - Use the defined Tone of Voice.
4.  **Self-Correction**: Read through once to ensure flow and clarity before submitting.

## Quality Checklist
- [ ] Headline is compelling?
- [ ] Introduction hooks the reader?
- [ ] Structure is logical?
- [ ] Tone matches the brief?
- [ ] Clear CTA included?
