# Task: Create Campaign

**Agent:** Strategist
**Input:** Topic, Brand Goals, Target Audience
**Output:** Comprehensive Campaign Brief

## Instructions

1.  **Analyze the Topic**: Research the provided topic. Identify key themes, trends, and questions the audience is asking.
2.  **Define the Audience**: Who is this for? What are their pain points? Create a micro-persona if needed.
3.  **Determine the Goal**: What is the business objective? (e.g., Lead Gen, Brand Awareness, Thought Leadership)
4.  **Develop the Strategy**:
    - **Core Message**: One sentence that summarizes the entire campaign.
    - **Tone of Voice**: How should we sound? (e.g., Professional, witty, empathetic)
    - **Channels**: Where will this content live? (e.g., Blog, LinkedIn, Email)
5.  **Create Content Plan**: List specific content pieces (Article titles, Social posts) that will support this campaign.
6.  **Deliver Brief**: Format the output as a Markdown brief ready for the Writer.

## Example Output Format

```markdown
# Campaign Strategy: [Topic]

**Goal:** [Goal]
**Audience:** [Audience]
**Core Message:** [Message]

## Content Plan
1.  **Article:** [Title]
    - *Brief:* [Short description]
2.  **Social Post:** [Platform]
    - *Angle:* [Hook]
```
