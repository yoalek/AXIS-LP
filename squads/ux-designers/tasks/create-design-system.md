# Tarefa: Criar/Atualizar Design System

**Objetivo:** Garantir consistência e escalabilidade da UI.

## Passos
1.  **Auditoria:** Revisar UI existente por inconsistências.
2.  **Definir Átomos:** Cores, Tipografia, Espaçamento, Ícones.
3.  **Definir Moléculas:** Botões, Inputs, Cards.
4.  **Definir Organismos:** Cabeçalhos, Rodapés, componentes complexos.
5.  **Documentar:** Criar diretrizes de uso para cada componente.

- Biblioteca Figma / Biblioteca de Componentes de Código
- Documentação
