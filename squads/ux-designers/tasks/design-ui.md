# Tarefa: Design de UI

**Objetivo:** Criar interfaces de alta fidelidade.

## Passos
1.  **Rascunho (Sketch):** Conceitos de baixa fidelidade no papel/quadro branco.
2.  **Wireframe:** Layout estrutural sem polimento visual.
3.  **Alta Fidelidade (High-Fi):** Aplicar design visual (cores, tipografia, imagens).
4.  **Protótipo:** Adicionar interações e transições.

## Entregáveis
- Mockups de alta fidelidade
- Protótipo Interativo
