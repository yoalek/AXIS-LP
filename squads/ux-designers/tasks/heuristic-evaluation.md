# Tarefa: Avaliação Heurística

**Objetivo:** Inspeção especializada de uma interface contra princípios de usabilidade estabelecidos.

## Passos
1.  **Walkthrough:** Percorrer os fluxos principais do usuário.
2.  **Inspecionar:** Avaliar cada tela contra as 10 Heurísticas de Nielsen.
3.  **Classificar Severidade:** 0 (Sem problema) a 4 (Catástrofe de Usabilidade).
4.  **Recomendar:** Propor correções específicas para cada violação.

## Entregáveis
- Relatório de Avaliação Heurística (com Classificação de Severidade)
